Where the data comes from

A realistic dataset from a public API

1 · DummyJSON API

Free e-commerce test data, no key needed

  • GET /users → customers
  • GET /carts → orders

2 · Convert

In sample_data.py

  • USD → INR at ₹83
  • Spread over 12 months
  • Realistic paid / pending mix
  • 12 recurring expenses

3 · Save

Through db.py into PostgreSQL

  • IDs start with sample-
  • Removable in one click
  • Offline generator if API is down
Real Amazon data? Amazon has no public API for customer data. The Selling Partner API returns only a seller's own orders and needs a registered developer app. So the app imports the All Orders report a seller downloads from Seller Central: each Amazon order becomes an invoice.

Debugging

Solving the 502 Bad Gateway

Problem 1

App never started

The repo had no start command, so Railway did not know how to run it.

click to flip
Fix

railway.json + Procfile

Start command, health check and restart policy added.

Problem 2

Still 502 after setup

Fixes were on a feature branch. Railway kept deploying old main.

click to flip
Fix

Merged into main

Railway redeployed automatically on push.

Problem 3

Wrong port risk

Streamlit defaults to 8501; Railway routes traffic to $PORT.

click to flip
Fix

start.py launcher

Reads PORT in Python and binds to 0.0.0.0. No shell expansion needed.

Also fixed: data loss on redeploy (moved to PostgreSQL) and slow database hangs (10-second connect timeout).
